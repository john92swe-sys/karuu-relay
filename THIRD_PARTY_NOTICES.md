# Acknowledgements and provenance

KARUU Relay is an independently written implementation. This release does not
include FreeLLMAPI source code or its model catalog.

The idea of bringing multiple provider allowances behind a local gateway was
inspired in part by [FreeLLMAPI](https://github.com/tashfeenahmed/freellmapi).
That project is MIT licensed and has a substantially broader feature set.
KARUU Relay is not affiliated with or endorsed by its maintainers or by any
model provider.

The server and dashboard use Node.js and browser standard APIs. There are no
third-party runtime npm dependencies in version 0.1.0. CI uses GitHub Actions.

The MIT license applies to this repository's software. Provider credentials,
models, services, free allowances, data handling, and permitted uses remain
subject to the selected providers' terms. A compatible API format does not
grant access to any provider's models or subscription.
